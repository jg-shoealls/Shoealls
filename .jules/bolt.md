## 2025-02-18 - PyTorch MultiheadAttention Memory Efficiency
**Learning:** In this codebase's PyTorch implementation (`src/models/fusion.py`), `nn.MultiheadAttention` is heavily used but the returned attention weights are often immediately discarded (assigned to `_`). Leaving default behavior forces PyTorch to calculate and return these weights, consuming unnecessary VRAM and preventing the use of optimized fast-path attention backends (e.g. FlashAttention or Memory-Efficient Attention).
**Action:** When finding `nn.MultiheadAttention` where the second output tuple element is discarded, always add `need_weights=False` to enable backend optimizations, but verify first that the weights aren't explicitly unpacked and used downstream (e.g. `cross_verify` in `reasoning_engine.py`).
