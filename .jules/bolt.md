## 2024-05-24 - [Optimize MultiheadAttention with need_weights=False]\n**Learning:** PyTorch's `nn.MultiheadAttention` computes attention weights by default, which can cause unnecessary computation and memory allocation if these weights are just discarded or unused downstream. By explicitly passing `need_weights=False`, we can enable optimized attention backends (like FlashAttention) and improve performance.\n**Action:** When using `nn.MultiheadAttention`, always check if the returned attention weights are actually used. If they are unpacked but unused, rename the unpacking target to `_` and pass `need_weights=False` to the forward call.
