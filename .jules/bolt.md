## 2024-05-07 - PyTorch MultiheadAttention Optimization
**Learning:** In PyTorch, calling `nn.MultiheadAttention` with the default `need_weights=True` unnecessarily allocates memory and computes attention weights even if they are immediately unpacked and discarded (e.g. `attn_out, _ = self.self_attention(...)`). By setting `need_weights=False`, we avoid this overhead and allow PyTorch to use faster attention backends like FlashAttention under the hood. However, this is only safe to do when the attention weights are explicitly unpacked to an ignored variable `_` or unused entirely.
**Action:** Always check the usage of PyTorch `nn.MultiheadAttention` returns. If the second return value (attention weights) is discarded, ensure `need_weights=False` is passed as a keyword argument to optimize memory allocation and computation time.
