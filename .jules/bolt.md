## 2025-07-22 - PyTorch MultiheadAttention Optimization
**Learning:** PyTorch's `nn.MultiheadAttention` computes attention weights by default, which incurs overhead in memory and computation. In models like `CrossModalAttentionFusion` and `CrossModalEvidenceCollector`, the returned attention weights (e.g., `cross_attn_weights`) were unpacked but completely discarded or ignored downstream. This is a common performance anti-pattern.
**Action:** When using `nn.MultiheadAttention` and the resulting attention weights are not needed for loss calculation or visualization downstream, always explicitly set `need_weights=False` in the forward pass. If the weights were previously unpacked to a named variable (e.g., `cross_attn_weights`), rename the unpacking target to `_` to prevent linting errors (like unused variables) and enforce clear intent.
