## 2026-08-09 - PyTorch nn.MultiheadAttention need_weights Optimization Note
**Learning:** In PyTorch, applying `need_weights=False` to `nn.MultiheadAttention` allows for a significant memory and computation optimization by skipping the allocation of attention weights matrices. However, in this codebase (e.g. `src/models/reasoning_engine.py`), the explicitly unpacked weight variable (e.g., `cross_attn_weights`) may be used downstream to compute domain-specific features like cross-modality agreement/support. Blindly setting `need_weights=False` and ignoring the return value when it is actually used leads to a `NameError`.
**Action:** Before optimizing away returned attention weights, carefully check the subsequent code block to ensure the explicitly unpacked variables are genuinely unused. If they are used (such as for cross-modality calculations), do not apply the `need_weights=False` optimization.
