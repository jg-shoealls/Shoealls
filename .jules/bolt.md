## 2024-05-24 - PyTorch MultiheadAttention Optimization
**Learning:** By default, `nn.MultiheadAttention` computes and returns attention weights (`need_weights=True`), which allocates additional memory and compute overhead. In contexts where these attention weights are never used downstream (e.g., in standard Transformer blocks or feature extractors where only the output tensor is needed), this creates an unnecessary performance bottleneck. Furthermore, when `need_weights=False`, PyTorch can leverage highly optimized backends like FlashAttention for significantly faster execution and lower memory footprint.
**Action:** Always set `need_weights=False` in `nn.MultiheadAttention` forward passes unless the attention weights are explicitly required for downstream logic (e.g., visualization or specific architectural mechanisms). When unpacking the return tuple, if the weights variable is unused, rename it to `_` to clearly signal the intent.
