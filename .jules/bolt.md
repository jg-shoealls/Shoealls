## 2024-05-24 - [PyTorch MultiheadAttention Memory Optimization]
**Learning:** By default, `nn.MultiheadAttention` computes and returns attention weights along with the output tensor. In this codebase's Multimodal fusion networks (`src/models/fusion.py`, `src/models/reasoning_engine.py`), these attention weights were being discarded (`_, _ = self.attn(...)`) or unpacked into unused variables. Leaving this default behavior leads to unnecessary memory allocation and compute overhead during training and inference.
**Action:** When using `nn.MultiheadAttention` where the returned attention weights are not needed, always pass `need_weights=False`. This prevents the overhead and allows PyTorch to utilize highly optimized, memory-efficient attention backends like FlashAttention under the hood. Replace unused target variables with `_` to be explicit.
