## 2025-02-23 - [Optimization] Prevent unnecessary attention weight computation in MultiheadAttention
**Learning:** In PyTorch's `nn.MultiheadAttention`, if the attention weights are not needed downstream, they still get computed and allocated by default. If the returned weights are unused (e.g. explicitly unpacked into a named variable like `cross_attn_weights` that isn't used, or discarded with `_`), we can optimize the operation by setting `need_weights=False`. This allows the usage of optimized attention backends (like FlashAttention) and reduces memory allocation.
**Action:** When working with PyTorch's `nn.MultiheadAttention`, always check if the attention weights are actually used. If they are discarded, set `need_weights=False` and, if previously unpacked into an unused named variable, safely rename the target to `_` to prevent unnecessary computation and memory usage. Add a comment to explicitly explain the optimization.
