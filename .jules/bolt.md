## 2024-05-24 - PyTorch MultiheadAttention Optimization
**Learning:** PyTorch's `nn.MultiheadAttention` computes and returns attention weights by default, which can be computationally expensive and allocate unnecessary memory. Setting `need_weights=False` avoids this overhead when attention weights are not needed (enabling FlashAttention and other optimized backends). However, avoid applying it if the returned attention weights are explicitly unpacked into a named variable (e.g., `cross_attn_weights`) because unpacking `None` causes hidden regressions or breaks expected downstream usage.
**Action:** When optimizing `nn.MultiheadAttention`, always check if the returned weights are actually used. If they are discarded (e.g. `attn_out, _ = self.attn(...)`), add `need_weights=False`.
