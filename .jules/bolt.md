## 2024-10-05 - Optimize MultiheadAttention Memory and Compute
**Learning:** PyTorch's `nn.MultiheadAttention` computes attention weights by default, which consumes memory and prevents FlashAttention fast-path if weights aren't explicitly discarded inside the forward pass when not needed. Setting `need_weights=False` avoids this unnecessary computation and memory allocation if attention weights are discarded, enabling FlashAttention. However, doing so will break downstream trace/reasoning components if they unpack and use the returned weights.
**Action:** When using `nn.MultiheadAttention`, explicitly pass `need_weights=False` if attention weights are not needed (e.g. they are ignored using `_`). Add an explanatory comment if discarding them explicitly. Ensure downstream components do not depend on the returned weights before applying this optimization.
