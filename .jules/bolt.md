## 2024-06-25 - [Optimization] PyTorch `nn.MultiheadAttention` backend optimization with `need_weights=False`
**Learning:** PyTorch's `nn.MultiheadAttention` computes attention weights by default. If we don't need these weights (which are typically returned as the second element of the tuple), adding `need_weights=False` avoids computing and allocating them. This is essential for FlashAttention/optimized attention backends to activate, saving both time and memory overhead. However, be extremely careful not to do this if the return values are unpacked into named variables (e.g., `out, cross_attn_weights = self.attn(...)`), as some downstream logic might silently depend on `cross_attn_weights` not being `None`.
**Action:** When working with PyTorch attention models, check if the returned weights are just ignored (e.g., `attn_out, _ = self.attn(...)`). If so, add `need_weights=False`. Always read the code to ensure we don't accidentally break explicit use cases where the weights are actually retained.
