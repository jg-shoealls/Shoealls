## 2023-10-24 - Cross-Modal Attention Forward Pass Bottleneck
**Learning:** In PyTorch, using `nn.MultiheadAttention` internally calculates attention weights by default (`need_weights=True`), which prevents the use of optimized fast attention paths (like FlashAttention) and uses more memory and compute. If `attn_weights` are unused (e.g. `_, _ = self.self_attention(...)` or `attn_out, _ = ...`), we should explicitly set `need_weights=False` to unlock potential internal performance improvements.
**Action:** When using `nn.MultiheadAttention`, explicitly set `need_weights=False` if the attention weights are unused. Check instances like `CrossAttentionBlock` and `CrossModalAttentionFusion` in `src/models/fusion.py`, and `CrossModalEvidenceCollector` in `src/models/reasoning_engine.py` (however, in `reasoning_engine.py` it's `cross_out, cross_attn_weights = self.cross_verify(summaries, summaries, summaries)` which might use `cross_attn_weights` downstream, though wait, `cross_attn_weights` is assigned but NOT used in `src/models/reasoning_engine.py` line 136).
