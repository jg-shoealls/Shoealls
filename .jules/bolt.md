## 2024-05-14 - [FlashAttention optimization in PyTorch]
**Learning:** PyTorch's `nn.MultiheadAttention` will allocate memory for attention weights and compute them explicitly unless `need_weights=False` is passed to the `forward()` method. When `need_weights=False`, PyTorch can use FlashAttention to massively reduce memory usage and speed up execution, provided the hardware supports it and conditions are met. This codebase discards the attention weights in `src/models/fusion.py` (e.g. `attn_out, _ = self.cross_attn(...)`). In `src/models/reasoning_engine.py`, the weights are also unpacked but unused (`cross_out, _cross_attn_weights = self.cross_verify(...)`), so it's safe to discard them there as well by setting `need_weights=False`.
**Action:** Always verify if attention weights are actually used. If they are ignored (`_`), pass `need_weights=False` to unlock FlashAttention for better performance.
