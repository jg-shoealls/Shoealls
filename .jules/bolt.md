## 2024-05-18 - [Optimizing PyTorch MultiheadAttention for FlashAttention Compatibility]
**Learning:** By default, PyTorch's `nn.MultiheadAttention` computes and returns attention weights. This prevents the use of optimized attention backends like FlashAttention, which are significantly faster and use less memory but do not materialize the full attention matrix. In the multimodal fusion and reasoning engine (`src/models/fusion.py`, `src/models/reasoning_engine.py`), the attention weights were either unused (`_`) or unpacked into named variables (`cross_attn_weights`) but entirely unused downstream.
**Action:** When using `nn.MultiheadAttention` where attention weights are discarded or unused downstream, always set `need_weights=False`. If a variable is unpacked but unused, rename it to `_` and pass `need_weights=False` to safely enable optimized attention computations, saving unnecessary computation and memory allocation.
