## 2024-07-01 - [Fixed KeyError in gait prediction pipeline]
**Learning:** The default CI configuration expects `num_classes: 11` (or dynamic), but the `GAIT_CLASS_NAMES` mapping in `api/service.py` is hardcoded to map only classes 0-3 (`normal`, `antalgic`, `ataxic`, `parkinsonian`). During test time, when `MultimodalGaitNet` returned a dummy prediction index > 3, it caused `KeyError` crashes in `classify()`, `analyze()`, and `reasoning()`. In `reasoning()`, `model.explain()` also crashed because `CLASS_NAMES_KR` didn't have enough entries. Finally, the sum of `class_probabilities` needs to match exactly 1.0.
**Action:** When a mismatch exists between the model output bounds and the hardcoded mappings, extract only the valid classes (e.g., using `if i in GAIT_CLASS_NAMES`), re-normalize their probabilities so they sum to 1.0, and safely fallback to index 0 for the max predicted class if it's out of bounds. Also ensure dummy dimensions (like `mag_baro`) required by the forward pass are properly injected.
