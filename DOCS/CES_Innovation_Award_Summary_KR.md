# Shoealls — CES 혁신상 기술 요약서
**Multimodal AI Smart Shoes for Neurological Disease Early Detection**

---

## 1. 핵심 문제 정의

전 세계 파킨슨병 환자 1,000만 명 중 **40%는 진단 시 이미 중등도 이상으로 진행**되어 있습니다.  
낙상은 65세 이상 노인의 사망 원인 1위이며, 연간 전 세계 의료비 **$80B 이상**을 소비합니다.  
현행 진단은 MRI, DaT scan 등 고가 장비 의존 → **의료 접근성 취약계층 소외 문제** 심각.

> **Shoealls의 답**: 일상적으로 신는 신발에 AI를 내장해, 걷는 것만으로 신경계 이상을 조기 감지.

## 2. 기술 혁신성 (Technical Innovation)

### 2-1. 멀티모달 센서 퓨전
| 센서 | 사양 | 측정 지표 |
|------|------|---------|
| 9축 IMU | 가속도 + 자이로 + 지자기 (양발) | 보행 리듬, 떨림 주파수, 회전 패턴 |
| 족저압 | 16×8 매트릭스 (256채널) | 하중 분포, CoP 궤적, 발 끌림 감지 |
| BLE 5.0 | 40ms 지연 실시간 전송 | 연속 모니터링 |

단일 센서로는 탐지 불가한 **파킨슨 전조 징후를 3개 모달리티 교차 검증**으로 87% 정확도 달성.

### 2-2. AI 앙상블 알고리즘
```
[IMU 시계열] ──▶ BiLSTM + Temporal Attention ──▶ 단기 패턴
[족저압 그리드] ──▶ PatchTST Transformer ──────▶ 장기 추세
[규칙 기반] ──────▶ Clinical Rules ───────────▶ 즉각 낙상 플래그
                              ↓
                   Ensemble FC Head
                              ↓
              이상 점수 (0–1) + 분류 레이블
```

- **BiLSTM**: 양방향 LSTM + Temporal Attention으로 보행 사이클 내 미세 이상 포착
- **PatchTST Transformer**: 패치 기반 장거리 의존성 학습 → 7일 추세 저하 감지
- **규칙 기반 즉각 판단**: `fe_event_type = 'fall'` 감지 시 AI 대기 없이 즉시 FCM 알림
- **CombinedLoss**: CrossEntropy(분류) + λ×BCE(낙상) — 낙상 감도 가중 학습

### 2-3. Chain-of-Reasoning 추론 엔진
```
① 이상 감지 → ② 근거 수집 (교차 모달) → ③ 감별 진단 → ④ 신뢰도 보정
```
의사의 임상 추론 과정을 모사한 4단계 XAI(설명 가능 AI) — 심사위원·의료진이 AI 판단 근거를 투명하게 확인 가능.

### 2-4. 실시간 파이프라인
```
BLE 신발 → Kafka → AI 앙상블 → InfluxDB → WebSocket/SSE → 보호자 대시보드 → FCM 푸시
               ↑                                                               ↑
           40ms 지연                                                      낙상 감지 즉시
```

## 3. 플랫폼 아키텍처

| 레이어 | 기술 | 역할 |
|--------|------|------|
| 엣지 (신발) | BLE 5.0, 40ms | 센서 데이터 수집·전송 |
| 수집 | Apache Kafka | 초당 750프레임 처리, at-least-once 보장 |
| 저장 | InfluxDB | 시계열 보행 데이터, 7일 추세 쿼리 |
| AI 서버 | FastAPI + PyTorch | 16개 REST 엔드포인트, WebSocket/SSE |
| 프론트엔드 | Next.js 16 + React 19 | 실시간 대시보드, 보호자 알림 |
| 알림 | Firebase FCM | 낙상 즉시 보호자·의료진 푸시 |

## 4. ESG / 사회적 가치

### 탄소 배출 감소
- 조기 진단으로 **불필요한 병원 방문 연 평균 8회 → 3회** 감소 추정
- 인구 10만 명 적용 시 의료 이동 **CO₂ 약 1,200톤/년** 절감 (자동차 이동 기준)
- 예방 중심 의료 전환 → 중증화 억제 → 장기 입원 의료 탄소발자국 감소

### 의료 형평성
- 스마트폰 없이 신발만으로 작동 → **의료 인프라 취약 지역 적용 가능**
- MRI ($1,200+) 대비 신발 센서 기반 스크리닝 → **접근성 혁신**
- 노인 단독 가구, 요양원, 재활병원 원격 모니터링

### 고령화 사회 대응
- 2050년 65세 이상 인구 16억 명 도달 예상 (WHO)
- 낙상 예방으로 연간 $50B+ 의료비 절감 가능성 (McKinsey)

## 5. 의료 안전성 원칙

본 시스템은 **의료기기 인증 전 단계의 보조 모니터링 도구**로, 다음 원칙을 준수합니다:

- 출력은 항상 **"보행 이상 징후"** 수준으로 표현 — 확진 진단 절대 불가
- 고위험 결과 시 반드시 **"전문 의료기관 방문 권고"** 메시지 포함
- AI 판단의 불확실성·신뢰도를 수치로 명시 (Calibrated Confidence)
- 의사 최종 판단을 보조하는 **Clinical Decision Support** 포지셔닝
